# Conversor de Unidades

Un conversor de unidades web minimalista, diseñado para estudiantes que requieren precisión y claridad en los pasos de cálculo. 

Esta herramienta no solo entrega resultados, sino que desglosa el procedimiento matemático mediante el uso de unidades base del Sistema Internacional.

## Características Principales

* **14 Categorías de Magnitud:** Incluye Longitud, Área, Volumen, Masa, Tiempo, Velocidad, Aceleración, Fuerza, Presión, Densidad, Peso Específico, Energía, Temperatura y Potencia.
* **Renderizado Matemático:** Utiliza **MathJax 3** para mostrar resultados y fórmulas con notación de alta calidad (LaTeX).
* **Cálculo Paso a Paso:** Función interactiva que muestra el proceso de conversión, ideal para fines educativos.
* **Memoria de Usuario:** Historial de las últimas 10 conversiones guardado localmente en el navegador mediante `localStorage`.
* **Interfaz Adaptativa (Responsive):** Diseño optimizado para una experiencia fluida tanto en escritorio como en dispositivos móviles.
* **Precisión Científica:** Soporta notación científica (ej. `1.5e-3`) y maneja el límite del cero absoluto en temperaturas.

## Instalación y Uso

Al ser una aplicación de una sola página (*Single Page Application*), no requiere instalación:

https://saintunderman.github.io/matematica_santiago_fiore_conversor_unidades/

## Teoría Integrada

El proyecto incluye una sección de definiciones y fórmulas clave sobre:
* **Fuerza:** Definición del Newton ($1 \, \text{N} = 1 \, \text{kg} \cdot \text{m/s}^2$).
* **Presión:** El Pascal y su relación con la fuerza y el área.
* **Densidad y Peso Específico:** Diferencias conceptuales y fórmulas de cálculo ($\gamma = \rho \cdot g$).
* **Energía:** Definición del Joule y trabajo realizado.
